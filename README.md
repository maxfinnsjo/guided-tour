Guided Tour
A companion mobile web app that can set an itenerary, or import from various sources, as comma sep. list or json, or the app can be used in free roam mode (i.e no set itenerary) as user stops at a poi there will be some guidence offered/available.
Simple and unobtrusive ui, elegant fast and free "map" solution, customizable but with sane and free fast reliable defaults. 
Each poi has a flash card of digestible info, this app is first and foremost a helpful tool for an amateur tour guide.
App should contain an easy to access faq, most asked questions and answers about each poi.
